Integrity

Why you can trust the dates

A track record is only evidence if it cannot be revised after the fact. Three things enforce that here, and all three are checkable by anyone:

  • Every observation is a separate dated commit. The git history is the timestamp trail — you can see when any number here first appeared.
  • CI rejects edits to published history. A validator runs on every push and fails the build if an existing observation is modified, removed, or reordered. Appending is the only legal change.
  • Every statistic is computed in your browser from the raw data file, so this page cannot quietly disagree with the numbers behind it.

The reported Sharpe ratio is deliberately not the headline. Alongside it sits the minimum track record length — how long this record would have to run before that Sharpe could be told apart from luck at 95% confidence. While the record is short, the page says so plainly.
